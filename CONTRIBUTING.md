# Contributing

Thanks for your interest in SuggestedDate!

## Getting Started

```bash
git clone https://github.com/schwuk/SuggestedDate.git
cd SuggestedDate
swift build
swift test
```

Requires Swift 6.2+ and macOS 26+.

## Pull Requests

- Keep changes focused and small
- Add tests for new functionality
- Ensure `swift test` passes before submitting
- Follow existing code style

## Issues

Bug reports and feature requests are welcome via [GitHub Issues](https://github.com/schwuk/SuggestedDate/issues).
